# FamilyHub

PWA React + Supabase per la gestione condivisa di scadenze, abbonamenti,
garanzie, buoni e manutenzioni di un nucleo familiare italiano.

## Quick start

```bash
cp .env.example .env   # inserisci VITE_SUPABASE_ANON_KEY
npm install
npm run dev
```

Vedi [`CLAUDE.md`](./CLAUDE.md) per l'architettura completa: stack, schema
